# Matrix101 GitHub Fonts Edition - Features Summary

## Complete Matrix Screensaver System
- **101 Visual Effects** (modes 0-100): Full collection of matrix rain variations
- **12 Font Sizes**: Different text sizes for visual variety
- **Smart Font Cycling**: Automatically cycles through fonts after completing all 101 modes

## Font System Features
- **Auto Font Cycling Toggle**: Turn automatic font cycling ON/OFF via web portal
- **Manual Font Selection**: Set specific font size (0-11) via web interface
- **Persistent Settings**: Font preferences saved to ESP32 flash memory
- **Visual Feedback**: Shows "FONT X/12" when cycling occurs

## Web Control Portal
- **WiFi Access Point**: Hold screen for 3 seconds to activate
- **Complete Control Interface**:
  - Current Mode Selection (0-100)
  - Font Size Setting (0-11)  
  - Font Auto-Cycling Toggle (ON/OFF)
  - Auto-Advance Timer (30s/1m/10m/1h/OFF)
  - Speed Setting (Slow/Normal/Fast/Ludicrous)
  - Brightness Control (25%/50%/75%/100%)

## Hardware Compatibility
- **ESP32 Development Board** (320x240 TFT display)
- **Touch Screen Support** via XPT2046
- **Physical Button Support** for mode switching
- **WiFi Configuration Portal**

## Auto-Advance System
- **Configurable Timing**: 30 seconds to 1 hour per mode, or manual only
- **Smart Font Cycling**: Only cycles fonts when enabled in settings
- **Persistent Operation**: Continues indefinitely through all modes and fonts
